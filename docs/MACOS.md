# macOS development setup

Install: Xcode Command Line Tools, Homebrew, Git, Node.js LTS, pnpm, Rust/Cargo, Python 3.12+, FFmpeg, Docker Desktop, SQLite/Hugging Face/R2 tooling as needed.

Production FLUX/LTX/MuseTalk inference is expected on rented NVIDIA/CUDA workers. Mock mode exists specifically so the complete app can be developed and tested on macOS without CUDA.
