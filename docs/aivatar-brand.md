# Aivatar brand foundation

## Official asset

`frontend/public/logo-aivatar.png` is the canonical Aivatar production logo. It is copied
without modification from the approved supplied artwork. The file is used by the Next.js
application shell and favicon workflow.

Keep clear space around the logo equal to at least the height of the mark's inner person symbol. Do not stretch, recolor, outline, or recreate the asset. On compact dark UI surfaces, the full lockup remains the preferred treatment; the source artwork already includes the approved blue-and-white appearance.

## Dark product tokens

| Token | Value | Purpose |
| --- | --- | --- |
| `--bg` | `#050913` | Cinematic blue-black canvas |
| `--surface` | `#08101d` | Elevated navigation and panels |
| `--surface-2` | `#0b1320` | Inputs and secondary surfaces |
| `--surface-3` | `#101a2a` | Hover and selected support surfaces |
| `--accent` | `#087eff` | Primary actions and active state |
| `--accent-2` | `#26c9ff` | Highlight and focus color |
| `--text` | `#f6f9ff` | Primary text |
| `--muted` | `#a7b8d1` | Secondary text |

The system is dark-mode-first: use layered navy-black surfaces rather than neutral charcoal or pure black. Blue illumination should be controlled and reserved for calls to action, focus, and brand moments.

## Usage contexts

- **App shell / sidebar:** use the official logo on the deep-blue background with comfortable clear space.
- **Loading, onboarding, and authentication:** reuse the same asset and token system; do not introduce a substitute mark.
- **Favicon / app icon preparation:** derive a compact asset only from the approved artwork and preserve the original canonical file.
- **Documentation:** refer to the product exactly as **Aivatar**.
